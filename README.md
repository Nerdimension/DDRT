# DDRT
consider it as an local-first (local only at the moment) open alternative to Google Tasks, but the ambition is beyond that. it is fully browser based HTML app (web app), so can be run on any compatible OS/browser. however, it is mostly intended for PC n smartphone cross sync usage. it is currently in alpha stage, intended to be in beta stage within a next 2 weeks, and stable after this month ends

# if you want to contribute
if you are thinking filing a PR, consider keeping the PR as small as possible (by focusing on one PR per feature change, multiple PR for multiple)
